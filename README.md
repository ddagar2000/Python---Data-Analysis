🚗 1. Automobile Sales EDA
📌 Objective

To analyze automobile sales data to identify revenue-driving factors, high-performing segments, and seasonal demand trends.

📊 Dataset

Records: ~1,000+ rows

Features: ~10–15 columns

Key variables: Sales, Model, Year, Region, Revenue

🔎 Analysis Performed

Missing value handling

Outlier detection using boxplots

Time-based trend analysis

Region-wise revenue comparison

Product performance segmentation

📈 Key Insights

Top-performing model contributed ~25–30% of total revenue

Sales peaked during Q3 and Q4 indicating seasonal demand

One region consistently generated highest revenue per transaction

Revenue distribution showed heavy concentration in top 3 models

🎯 Outcome

Provided actionable insights into product performance and seasonal trends that could support inventory and marketing decisions.

📈 What Improved After This Project

Strengthened understanding of business-oriented EDA

Improved ability to convert raw sales data into strategic insights

Enhanced data visualization storytelling skills

📱 2. Google Play Store EDA & Feature Engineering
📌 Objective

To analyze app performance metrics and uncover patterns influencing app installs and ratings.

📊 Dataset

Records: ~10,000+ apps

Features: 13+ columns

Key variables: Rating, Reviews, Installs, Category, Price

🔎 Analysis Performed

Cleaned inconsistent entries (e.g., “Varies with device”)

Converted installs & price into numeric format

Log transformation of highly skewed features

Category encoding for modeling

Correlation matrix analysis

📈 Key Insights

Free apps had ~3x more installs than paid apps

Apps rated above 4.0 showed significantly higher download counts

Gaming category dominated install share (~20%+)

Reviews strongly correlated with installs

🎯 Outcome

Created a clean, feature-engineered dataset suitable for predictive modeling and ranking analysis.

📈 What Improved After This Project

Improved feature engineering skills

Learned handling of real-world messy datasets

Developed deeper understanding of correlation vs causation

🔮 Future Enhancements

Build classification model to predict high-install apps

✈️ 3. Flight Price Prediction Project
📌 Objective

To build a machine learning model to predict flight ticket prices based on travel details.

📊 Dataset

Records: ~10,000 rows

Features: Airline, Source, Destination, Duration, Stops, Date

🔎 Data Processing

Extracted journey day & month

Converted duration into numerical hours

One-hot encoded categorical variables

Removed multicollinearity

Scaled numerical features

🤖 Models Implemented

Linear Regression

Random Forest Regressor

📈 Model Performance

R² Score: ~0.80 – 0.85

Reduced prediction error significantly

Random Forest outperformed Linear Regression

📈 Key Insights

Ticket prices increase significantly with fewer stops

Certain airlines consistently priced higher

Seasonal fluctuations impacted fare prices

Duration and airline were strong predictors

🎯 Outcome

Successfully built a regression model capable of estimating ticket prices with strong accuracy.

📈 What Improved After This Project

Hands-on experience with supervised machine learning

Improved model evaluation and comparison skills

Stronger understanding of feature importance

🔮 Future Enhancements

Hyperparameter tuning using GridSearchCV

Try XGBoost / Gradient Boosting

Deploy as a web app using Streamlit or Flask
